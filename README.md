Helinart

Helinart is a luxury nail art and nail extension platform that blends premium design, expert artistry, and seamless salon booking into one elegant experience. Users can explore curated nail styles, discover nail artists, save favourites, view offers, and book personalized appointments through a modern beauty-focused interface.

✨ Features

Luxury top navigation experience

Premium nail art and extension catalogue

Nail design filtering by style and category

Favourite / like interaction with animated heart feedback

Appointment booking flow

Upcoming appointment tracking

Nail artist discovery and profiles

Offers, VIP rewards, and premium collections

Before & After showcase

Reviews and client feedback

Responsive desktop, tablet, and mobile layouts

Cinematic looping nail-art hero video

Gradient glass product cards with subtle hover shadows

❤️ Favourite Interaction

When a user likes a nail design:

The design is added to Favourites.

The heart icon becomes active.

A large Dusty Rose heart briefly pops over the nail image.

Small Champagne Gold sparkles appear around the heart.

The animation fades while the small favourite icon remains active.

The effect is inspired by modern social interactions while remaining visually consistent with the Helinart luxury identity.

🎬 Hero Experience

The hero section supports a cinematic looping video showing the nail-art extension process:

Natural Nail
→ Extension
→ Shaping
→ Nude Base
→ Dusty Rose Detailing
→ Champagne Gold Art
→ Pearlescent Finish
→ Final Nail Reveal

The video remains muted, loops seamlessly, and sits behind a soft Helinart gradient overlay so all text and product content remain readable.

🚀 Getting Started

Clone the repository:

git clone <your-repository-url>
cd helinart

Install dependencies:

npm install

Start the development server:

npm run dev

Then open the local URL shown in your terminal.
